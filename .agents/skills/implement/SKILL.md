Implement the work described by the user in the spec or tickets.

Follow `AGENTS.md`. Use [tdd](../tdd/SKILL.md) at agreed seams where appropriate.

Run focused tests as you work. Use [verify](../verify/SKILL.md) for the full required checks before committing.

Before committing, use [code-review](../code-review/SKILL.md) against the task's fixed base and include the work in progress.

Commit the verified work to the feature branch using the repository's Git conventions.
