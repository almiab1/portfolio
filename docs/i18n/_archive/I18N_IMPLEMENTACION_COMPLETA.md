### Fácil de Extender

   ```javascript
   // astro.config.mjs
   locales: ["es", "en", "fr", "de"]
   ```

2. **Añadir traducciones:**

   ```typescript
   // src/i18n/ui.ts
   'nueva.clave': 'Nueva traducción'
   ```

   ```yaml
   lang: "en"
   translationKey: "vinculo-unico"
   ```
